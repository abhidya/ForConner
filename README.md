# For Conner

Static holiday greeting card demo originally built on CodePen.

## Demo

- GitHub Pages: `https://abhidya.github.io/ForConner/`
- Source CodePen: `https://codepen.io/abhidya/pen/bGNRwVP`

## Run locally

This is a static HTML/CSS/JavaScript page. Serve the folder with any static server:

```sh
python3 -m http.server 4173
```

Then open:

```text
http://localhost:4173
```

You can also open `index.html` directly in a browser.

## Notes

- The page uses external image/font/CDN assets from CodePen-era sources, so the full card requires an internet connection.
- The original CodePen license page is available at `https://codepen.io/abhidya/pen/bGNRwVP/license`.
